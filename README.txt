SITE EDUCAȚIONAL DEMONSTRATIV — Educație pentru viitor

Pagini incluse:
- index.html (Home + căutare Google)
- discipline.html (casetă informativă, listă cu trei linkuri, galerie)
- marketing.html
- contabilitate.html
- antreprenoriat.html
- feedback.html
- resurse.html
- style.css

DE COMPLETAT ÎNAINTE DE PREDARE:
1. În resurse.html, înlocuiește linkul YouTube de căutare cu un videoclip educațional exact și creează un TinyURL pentru acel videoclip.
2. Adaugă CV-ul tău real ca fișier cv.pdf în acest folder (sau modifică linkul din resurse.html pentru un document public).
3. Pentru feedback cu istoric public în timp real, creează Google Form și conectează răspunsurile la Google Sheets; publică foaia și înlocuiește casetele demonstrative din feedback.html cu iframe-urile reale.
4. Publică întregul folder pe o platformă web (de exemplu GitHub Pages), apoi descarcă versiunea publicată cu HTTrack.
5. Arhivează folderul descărcat cu 7-Zip în format .7z.

Numele recomandat al arhivei:
